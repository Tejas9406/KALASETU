# Asset Management Rules

Every production asset should have:

1. Asset ID
2. Filename
3. Category
4. Source
5. Creator/author if available
6. License
7. Source URL
8. Direct download URL if available
9. Attribution requirement
10. Date obtained
11. Notes

All of this should be recorded in:

LICENSE/asset-register.csv

---

# Important Copyright Rule

Do not assume an image is reusable simply because it appears on:

- Google Images
- Pinterest
- Instagram
- Facebook
- Blogs
- News websites
- Travel websites
- Random websites

Always verify the original source and its license.

If the license is unknown:

DO NOT use the asset in the final production version.

It may be kept separately as a reference asset only.

---

# Preferred Sources

Prefer:

- Wikimedia Commons
- Unsplash
- Pexels
- Pixabay
- Government open-data/open-media sources
- Official tourism departments
- Other sources with clearly stated reusable licenses

Always verify the individual asset license where applicable.

---

# Naming Convention

Use descriptive filenames.

Example:

kolhapur_kolhapuri_chappal_workshop_01.jpg

sangli_tamboli_market_01.jpg

solapur_handloom_chadar_02.jpg

satara_folk_art_01.jpg

pune_traditional_craft_market_01.jpg

Avoid:

IMG001.jpg
photo1.jpg
final.jpg
newimage.png
download.jpg

---

# Quality Requirements

Prefer:

- High resolution
- Sharp images
- Clean composition
- Natural lighting
- Authentic-looking scenes
- Minimal watermarking
- Suitable aspect ratio
- Good visual storytelling

For PPT:

Prefer images that remain clear when projected.

For UI:

Prefer appropriately compressed WebP/JPEG versions.

Keep original/high-resolution versions when licensing permits.

---

# Regional Priority

For the initial Kala Setu prototype, prioritize:

1. Kolhapur
2. Sangli
3. Satara
4. Pune
5. Solapur

The platform should eventually support crafts and experiences from
all regions of Maharashtra and India.

---

# License Safety

When uncertain about a license:

Mark:

LICENSE STATUS = NEEDS VERIFICATION

Do not use it in production until verified.
